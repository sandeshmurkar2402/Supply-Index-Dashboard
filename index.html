Configure Live Refresh
The Refresh button triggers a GitHub Actions run that pulls the latest data from the Google Sheet directly, instead of waiting for the scheduled sync. It needs a GitHub token to do that.
Create a fine-grained PAT at GitHub:
  1. Go to github.com/settings/tokens?type=beta
  2. Click Generate new token
  3. Repository access → Only select repositories → this repo
  4. Permissions → Repository → Actions → Read and write
  5. Generate & copy the token, paste below
No token saved — live refresh runs on the scheduled sync only
